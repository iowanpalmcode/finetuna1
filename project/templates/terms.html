1. What this is

AIMotional is a demo tool for experimenting with a modular personality-trait system. The Arena mode generates two AI replies to your prompt, each shaped by a different, randomly assigned set of personality traits, and lets you vote for the one you prefer. It is provided for educational and experimental use, "as is," with no warranty of any kind.

2. No accounts, no persistence

There is no login or user account system. Agents you create exist only in the server's memory for as long as the process keeps running, and are permanently lost when the server restarts. Do not rely on this tool to store anything you need to keep.

7. Arena mode data

Each Arena prompt generates two replies, each shaped by 1-3 randomly assigned personality traits, and you vote for the one you prefer. The traits used, each reply's length, and which option won are stored and aggregated into public statistics shown on the Analytics page for anyone to see. See the Privacy Policy for exactly what is and isn't stored.
