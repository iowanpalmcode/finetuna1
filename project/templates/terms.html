1. What this is

The AI Agent Personality Builder is a demo tool for experimenting with a modular personality-trait system. It lets you combine traits and see how they would influence example text responses. It is provided for educational and experimental use, "as is," with no warranty of any kind.

2. No accounts, no persistence

There is no login or user account system. Agents you create exist only in the server's memory for as long as the process keeps running, and are permanently lost when the server restarts. Do not rely on this tool to store anything you need to keep.
